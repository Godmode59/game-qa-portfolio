# Oblivion 대화 진행과 연출 피드백

2025년 9월부터 2026년 1월까지 작업한 6인 팀 프로토타입입니다. QA 및 서브 기획으로 참여했습니다.

## 발견한 결함

| 항목 | 관찰한 동작과 조건 |
| --- | --- |
| 페이드 인 연출 | 일부 구간에서 화면이 깜빡임 |
| 컷신 이후 스킵 입력 | 컷신 종료 직후에는 스킵 키가 동작하지 않음. 텍스트 출력이 끝난 뒤에는 스킵 가능 |

2025년 11월 개발본에서 확인한 현상을 조건과 함께 팀에 전달했습니다.

## 텍스트 사용성 개선 의견

클릭하면 텍스트 출력 정도와 관계없이 바로 넘어가는 동작을 관찰했습니다. 텍스트 속도를 조절하거나, 첫 클릭에서는 전체 텍스트를 보여주고 다음 클릭에서 진행하는 방식을 제안했습니다.

결함 보고와 읽기 편의에 대한 개선 의견을 나눠 개발본 피드백으로 전달했습니다.
