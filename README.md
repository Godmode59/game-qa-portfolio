## 작업 방식과 도구

- **Excel·PowerPoint:** 사전 조건, 재현 절차, 기대·실제 결과를 정리한 TC와 버그 리포트 작성
- **Google Drive·Discord:** 팀 QA 폴더의 문서 갱신, 개발자 피드백 및 변경 사항 공지
- **Unity·C#:** 기존 스크립트 읽기, UI·광고 문제의 원인 조사와 수정 참여

각 사례는 당시 작성한 자료를 바탕으로 정리했습니다. 수정·재검증 기록이 없는 항목은 발견·보고 경험으로 표기했습니다. RollingRolling의 코드 조사·수정에는 GPT의 도움을 활용했습니다.
